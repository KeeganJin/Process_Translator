# Process Model (Petri Net) Translator  
**Collaborative Project with [RWTH PADS Group](https://www.pads.rwth-aachen.de/cms/~pnbx/pads/?lidx=1)**  

This repository is part of a collaborative thesis project with the RWTH Aachen **Process and Data Science (PADS)** group.  
It serves as an **extension of a master’s thesis**, providing an end-to-end platform for a **pattern detector** and our customized **Retrieval-Augmented Generation (RAG)** framework.  

For more details on the underlying research, please refer to the original thesis:  
[Master Thesis – LLM-Based Process Model Translation](https://www.pads.rwth-aachen.de/cms/PADS/studium/Abgeschlossene-Abschlussarbeiten/2025/~bpxafw/Master-Thesis-LLM-Based-Process-Model/lidx/1/)
